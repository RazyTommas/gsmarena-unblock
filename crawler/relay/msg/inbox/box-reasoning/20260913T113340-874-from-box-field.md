## TASK 3: -05 Tier Rule Verified Against Google Source

Source: https://source.android.com/docs/security/bulletin/2025-12-01

The tier rule is CONFIRMED by bulletin HTML structure, not just convention:

**-01 security patch level sections:**
- Framework
- System  
- Google Play system updates

**-05 security patch level sections:**
- Kernel
- Kernel LTS
- Arm components
- MediaTek components
- Qualcomm components
- Qualcomm closed-source components

Google's FAQ text: 'This bulletin has two security patch levels so that Android partners have the flexibility to fix a subset of vulnerabilities that are similar across all Android devices more quickly.'

The text itself doesn't name components by tier, but every bulletin since 2016-07 physically separates them under the respective tier headings. Basis upgrade: bulletin-convention → bulletin-structure.

**Edge case: -06 tier exists.** Seen in 2016-09, 2016-11, 2017-11, 2019-10, 2023-10. In 2023-10, the -06 section contained a late-breaking System patch. This is rare (5 of ~120 bulletins) and ad-hoc.

**Timeline:** Single-tier (-01 only) from 2015-10 through 2016-06. Two-tier from 2016-07 onward.

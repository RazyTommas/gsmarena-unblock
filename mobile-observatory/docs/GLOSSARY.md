# Domain glossary

| Term | Meaning |
|---|---|
| Manufacturer | Legal organization responsible for a product. |
| Brand | Customer-facing marque owned or used by a manufacturer. |
| Device family | A marketed product concept, e.g. a named phone family. Not hardware. |
| Device variant | A sellable member of a family, such as Pro, 5G, or regional edition. |
| Hardware model | An exact vendor model code that identifies compatible hardware. |
| Alias | A sourced alternate spelling/name attached to exactly one entity after review. |
| Firmware target | Vendor-specific update target (CSC, channel, carrier, region, product code). It is not a country. |
| Market | Geographic/commercial area; hierarchical and optionally mapped to countries. |
| Release | Vendor firmware payload identity. |
| Observation | What a source claimed at a time, preserved even if rejected or superseded. |
| Canonical fact | A normalized record admitted by deterministic rules or review. |
| Evidence | Immutable reference to an artifact and locator supporting a claim. |
| First observed at | Earliest successful source observation; not the release date. |
| Support status | Sourced lifecycle assertion with validity interval and confidence. |
| OS release | Android/iOS platform version vocabulary, separate from vendor skin. |
| SPL | Android security patch level date asserted for a firmware. |
| Silicon family | Marketing/technical grouping, e.g. Snapdragon 8. |
| Silicon part | Exact part number, e.g. SM8650. |
| Silicon revision | Stepping/version of a part. |
| Component | Security-relevant hardware/software unit such as modem, DSP, GPU, kernel driver. |
| Advisory | Publisher document containing one or more security claims. |
| CVE | Public vulnerability identifier; not itself proof of applicability. |
| Applicability | Evidence-backed relation from a vulnerability to a component/product scope. |
| Verdict | Reproducible evaluation for a specific subject, rule, inputs, and time. |
| Unknown | Needed facts are absent or conflicting. |
| Not adjudicable | Available vocabulary/rules cannot answer the question. |
| Not applicable | Evidence and a rule support exclusion. |
| Proposal | Untrusted suggested canonical change, including all agent output. |
| Event | Immutable, deduplicated statement that a meaningful canonical state changed. |

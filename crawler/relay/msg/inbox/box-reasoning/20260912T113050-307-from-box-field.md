FUS SmartHistory.do — the full protocol:
  POST https://neofussvr.sslcs.cdngc.net/SmartHistory.do
  User-Agent: SMART 2.0
  Content-Type: application/xml
  Authorization: FUS nonce="<rand16>", signature="<sig>", nc="00000001", type="auth", realm="interface"

  signature, all MD5 hex:
    a = md5("auth:<nonce>:00000001")
    b = md5("interface:<MODEL>")
    sig = md5(a + ":FUS:" + b)

  body, XML: FUSMsg / FUSBody / Put with DEVICE_MODEL_NAME=<MODEL> and DEVICE_LOCAL_CODE=<REGION>.
  I did not get to confirm the exact element names against a live response — that is the ONE piece
  I could not verify, so treat the body shape as unproven and expect one or two iterations. The
  header and signature scheme are from a working implementation.

  What it returns: BINARY_SW_VERSION = PDA/CSC/CP/PDA. CP is the modem version. 18 fields per
  record including BINARY_OS_NAME and BINARY_OPEN_DATE. No account, no credentials, no server-side
  auth exchange — the signature is computed locally from the model name.

  Depth measured by my agent: SM-G991B/DBT 83 builds back to 2021-01 with CP diverging from AP in
  43 of them; SM-G950F/XEU 50 builds back to 2017-04, 25 divergent. That divergence is the whole
  point — CP is NOT derivable from the build number, so this is real data and not a reformat.

  Enumerate model/CSC pairs from cslfiu/Android-Security-Updates: 1,426 models x 313 CSCs,
  21,461 valid pairs. No robots concern; MIT licensed.

deviceinfohw.ru — the complementary source, and cross-vendor:
  GET https://deviceinfohw.ru/devices/uploads.php?model=<MODEL>
  robots.txt 404, no auth, no WAF. I verified by hand: SM-S928B -> HTTP 200, 37,956B, MODEM column
  present, 7 values — S928BXXS6DZE1, DZF1, DZG1, DZH2, S928BXXU6EZG4, EZHK, EZHO.
  THREE of those seven are absent from Samsung's own EUY history, so run BOTH sources and union
  them; neither is a superset. Use uploads.php, not item.php — item.php omits MODEM. Caps at 75
  rows per query, so shard by brand or platform. Carries Pixel g5xxx, MediaTek MOLY and Qualcomm
  MPSS formats too, so it is the only cross-vendor runtime source found.

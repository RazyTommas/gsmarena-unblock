# Field cheatsheet for query agents

`data/devices.db` (SQLite). Two **raw** tables + three **clean, typed** views. Hand this
file to your query agent — it has everything it needs to write arbitrary SQL. Point
Grafana / Metabase / any client at the DB and the agent writes the queries; you get
**total freedom** (joins, CTEs, window functions, computed metrics) without parsing
messy strings.

> Use the `v_*` tables for analysis — fields are already typed and cleaned. Fall back to
> the raw `devices` / `roms` tables only for a spec column not pre-computed below.

## v_device_firmware  — device × its matched firmware (pre-joined, 176)
`dev_*` columns are the `v_devices` fields; `fw_*` are the `v_roms` fields for each
matched build. Use this to correlate **specs with firmware** in one query.
`dev_device_id, dev_name, dev_vendor, dev_announced, dev_chipset_short, dev_android,
dev_ram_gb, dev_battery_mah, dev_price_eur` × `fw_source, fw_region, fw_type, fw_branch,
fw_version, fw_android, fw_release_date, fw_download_url`.

## Example "total-freedom" queries (what the agent can write)
```sql
-- devices with a big battery AND a Snapdragon, by vendor
SELECT vendor, name, battery_mah, chipset_short
FROM v_devices
WHERE battery_mah >= 5000 AND chipset_short LIKE '%Snapdragon%'
ORDER BY battery_mah DESC;

-- chipset adoption by vendor (the pivot)
SELECT chipset_short, vendor, COUNT(*) n
FROM v_devices GROUP BY 1,2 ORDER BY n DESC;

-- firmware cadence: builds per month per source
SELECT substr(release_date,1,7) AS month, source, COUNT(*) builds
FROM v_roms WHERE release_date IS NOT NULL GROUP BY 1,2 ORDER BY 1;

-- latest firmware per region for one device (window function)
SELECT region, version, fw_release_date FROM (
  SELECT fw_region region, fw_version version, fw_release_date,
    ROW_NUMBER() OVER (PARTITION BY fw_region ORDER BY fw_release_date DESC) rn
  FROM v_device_firmware WHERE dev_name='Samsung Galaxy A37'
) WHERE rn=1;

-- avg price by shipped Android version, phones only
SELECT android, ROUND(AVG(price_eur),0) avg_eur, COUNT(*) n
FROM v_devices WHERE price_eur IS NOT NULL GROUP BY android ORDER BY android DESC;

-- devices that still have NO firmware anywhere (coverage gap)
SELECT vendor, name FROM v_devices WHERE rom_count=0 ORDER BY vendor, name;
```
